# Password Security Analyzer

## Project Description

Password Security Analyzer is a beginner-friendly cybersecurity project developed in Python.

The application analyzes a password and checks:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Common passwords
- Predictable patterns

The program calculates a simple security score and classifies the password as:

- WEAK
- MEDIUM
- STRONG

It also provides recommendations for improving password security.

## Technologies Used

- Python
- VS Code
- GitHub

## Features

1. Password length analysis
2. Character-type analysis
3. Common password detection
4. Predictable pattern detection
5. Security score
6. Password-strength classification
7. Security recommendations
